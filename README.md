One line, 128 characters, that excuses a missed deadline: the work was done,
it just went to the wrong group chat.

`main.ts` (Node 22, stdlib only, offline, deterministic) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, gated in code to 1–200 characters and
exactly one line.

> I didn't miss the deadline — I sent the finished file to the wrong group chat, and now twelve strangers think I'm very punctual.
